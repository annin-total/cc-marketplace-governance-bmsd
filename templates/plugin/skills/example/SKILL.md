# example

このファイルは雛形である。新しいプラグインを作るときは、このディレクトリごと
コピーし、`name`・`description`・本文を実際のスキルの内容に差し替える。

`description` は Claude がこのスキルを起動するかどうかの判断材料になる。
何をする時に使うスキルかが伝わるよう、具体的なトリガー語を含めて書く。

## 使い方

このセクションに、スキルが実行する手順を書く。
